Indonesia Localization Improvement
==================================

This module enhances the Indonesian localization of Odoo by providing:

* **Improved Translations**: Corrects Indonesian translations that are contextually inaccurate. For example, "State" in the Contacts menu is translated as "Provinsi" (Province) instead of "Status".
* **Default Currency**: Sets Indonesian Rupiah (IDR) as the default currency.
* **Default Country**: Sets Indonesia as the default country for partners and companies.
